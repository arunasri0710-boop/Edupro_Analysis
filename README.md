# EduPro Learner Analysis

## Project Overview
EduPro Learner Analysis is a data analytics project that studies learner details and course enrollment patterns on an online education platform.

## Objectives
- Analyse learners by age and gender.
- Identify popular course categories.
- Understand course-level preferences.
- Compare enrollment patterns across learner groups.
- Present insights through an interactive dashboard.

## Tools Used
- Python
- Pandas
- Google Colab
- Power BI

## Dataset
- Users
- Courses
- Transactions

## Key Findings
- Age group 26–35 recorded the highest enrollments (4,799).
- Female participation was 50.78%, and male participation was 49.22%.
- Data Science was the most popular category (916 enrollments).
- Beginner courses had the highest preference (35.73%).

## Dashboard
Created an interactive Power BI dashboard to display learner distribution, gender participation, course popularity and course-level preferences.
